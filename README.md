## SLE-3 Architecture
This repository documents the same AI Agent system using all four C4 levels:
1. **Context** – User and Simple AI Agent interaction
2. **Container** – Input/Console, Text Processor, Rule/Intent Matcher, Response Generator, Conversation Loop
3. **Component** – Internal parts of the Rule/Intent Matcher
4. **Code** – Main Python function, rules, input, loop and exit handling

## How to Run
Run: `python Agent.py`

Type questions such as: hello, What is Python?, What is GitHub?, help, What is your name?
Type **bye** to exit.
